# Landing Profesionales — Certificación para Profesionales

## Descripción General

Página de aterrizaje dirigida a profesionales individuales (docentes, consultores, facilitadores) que buscan certificarse o mejorar sus competencias. Presenta los programas de certificación, beneficios del plan personal y un formulario de captación de leads.

**Ruta:** `/certificacion`
**Componente:** `src/pages/LandingProfesionales.tsx`
**Layout:** `PublicLayout`

---

## Funcionalidades — User Stories

### Presentación del programa
- Como **profesional independiente**, quiero ver los programas de certificación disponibles para evaluar si se alinean con mi desarrollo profesional.
- Como **profesional**, quiero conocer los beneficios de certificarme con Cademmy para justificar mi inversión.
- Como **profesional**, quiero ver los precios y modalidades (en línea/presencial) para planificar según mi presupuesto y tiempo.

### Captación y conversión
- Como **profesional interesado**, quiero llenar un formulario de contacto para recibir más información sin compromiso.
- Como **profesional listo para inscribirse**, quiero acceder directamente al proceso de pago para iniciar mi certificación rápidamente.
- Como **profesional**, quiero agendar una llamada o cita para resolver mis dudas antes de inscribirme.

### Confianza y credibilidad
- Como **profesional**, quiero ver casos de éxito o testimonios de otros profesionales certificados para confiar en el programa.
- Como **profesional**, quiero saber qué organismos avalan las certificaciones (e.g., CONOCER) para valorar el reconocimiento oficial.

### Seguimiento de marketing
- Como **equipo de marketing**, quiero que los parámetros UTM se capturen automáticamente al registrar un lead para medir el rendimiento de campañas.
