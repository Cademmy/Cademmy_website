# Landing Formador 4.0 — Programa para Instructores

## Descripción General

Página de aterrizaje dedicada al programa "Formador 4.0", dirigido a instructores, facilitadores y docentes que quieren modernizar su práctica educativa incorporando tecnología, inteligencia artificial y metodologías activas. Presenta el programa, módulos, beneficios y convocatoria de inscripción.

**Rutas:** `/formador-4-0` (principal) · `/instructor-4-0` (alias legacy)
**Componente:** `src/pages/LandingInstructor40.tsx`
**Layout:** `PublicLayout`

## Funcionalidades — User Stories

### Presentación del programa
- Como **instructor o docente**, quiero ver el contenido y módulos del programa Formador 4.0 para evaluar si cubre las competencias que necesito desarrollar.
- Como **facilitador**, quiero conocer la metodología del programa (presencial, en línea, mixta) para elegir la modalidad que mejor se adapta a mi agenda.
- Como **instructor**, quiero ver el perfil de egreso del programa para saber qué certificación o reconocimiento obtendré al concluirlo.

### Inscripción y conversión
- Como **instructor interesado**, quiero registrarme o dejar mis datos para recibir información sobre la próxima convocatoria.
- Como **instructor listo para inscribirse**, quiero acceder al proceso de pago del programa directamente desde la landing para agilizar mi inscripción.

### Comunidad y networking
- Como **instructor**, quiero saber si el programa incluye acceso a una comunidad de formadores para ampliar mi red profesional.

### Contenido de valor
- Como **instructor**, quiero ver recursos gratuitos (webinars, artículos) relacionados con la formación 4.0 para evaluar la calidad del contenido antes de inscribirme.

### Seguimiento
- Como **equipo de marketing**, quiero capturar UTM y fuente de tráfico al registrar leads del programa para optimizar las campañas de adquisición.
